# Simplified Step-by-Step Guide: How to Use the Simulator

Welcome! Follow these simple steps to set up and run the simulator on your computer.

---

## Step 1: Download the Files
* Download everything inside the `simulateur_v5` folder.
* **Important:** Keep all files and subfolders in their original structure.
* *(Optional)* Download `README.md` as well for quick reference, or simply keep the documentation page open in your browser.

---

## Step 2: Customize Your Settings
* Right-click `main.py` and open it with **Notepad** (or any text editor).
* This is where you can adjust the simulator parameters to suit your needs.
* The rules, keywords, and formatting syntax are explained in `README.md`. It might take a minute to get used to, but it is quite straightforward!

---

## Step 3: Install Python
* Open the **Microsoft Store** on your Windows PC.
* Search for **Python** and install the latest available version (it is lightweight and installs quickly).

---

## Step 4: Install Required Packages
* Open **Command Prompt** or **Windows Terminal**.
* Copy and paste the following three commands, pressing **Enter** after each line:

```bash
pip install --upgrade pip
pip install numpy
pip install pandas
```

---

## Step 5: Run the Simulator
* Open your Terminal inside the `simulateur_v5` folder.
* Type the following command and press **Enter**:

```bash
python main.py
```

---

## Step 6: Enjoy!
Your simulation is now ready and running!

---

> ⚠️ **Troubleshooting Note (Execution Policy Error):**
> If Windows stops you with a message stating that `ExecutionPolicy` prevents script execution, don't panic—this is a standard Windows security setting. Search online for *"How to fix PowerShell Execution Policy"* for safe steps to enable script execution on your PC.
